# 固定示范真机回放（未做现场验收）

在仓库根目录运行。无需 VR、相机、策略网络或训练权重；需要本地 23 号处理后示范和官方驱动环境。

1. `bash run_dp.sh --fixed-replay 0 --inspect-only`：只核对文件、SHA、逐轴范围/速度及模型离散碰撞，不打开 CAN。每个档位使用同一组 `action`，不用 `obs` 作指令。
2. 确认没有 VR、DP、旧版驱动或其他 CAN 工具占用，按既有流程准备好 CAN；本入口不重配活动总线。现场应有实体急停和失能后的安全承托，包括终点及中途停机的位置。运行 `bash run_dp.sh --fixed-replay 0`，初次是双臂未使能状态检查，不自动运动。
3. 两侧各八轴均有新鲜未使能回包，现场确认后输入 `START` 回车：使能并直接回**加宽启动位**。相对厂商官方位，模型左右末端控制点沿机座 Y 分别平移 +4 cm、−4 cm，间距由 30.5 cm 增至 38.5 cm；前后、高度、末端朝向及夹爪开度目标不变。仅固定回放使用该姿态，不平移示范。确认到位、实物环境与过渡路径后，输入 `APPROACH` 回车：限速到试验起点。从实际起始反馈到加宽位、从加宽标称位和回位后反馈到片段首帧均有离散模型检查；不验证现场几何，也不是对真实动力学路径的保证。
4. 保持起点时逐步升至该档位，经双侧确认后输入 `GO` 回车。保持 3 s、运动 4 s、终点保持 3 s，只播一次，不折返。结束提示后约 3 s 自动请求失能、不回停车位。阶段有等待超时，不能依赖无限保持来支撑手臂。
5. `STOP` 回车或 `Ctrl+C` 请求两侧停止；危险时现场实体急停，不等待程序。看两侧新回包是否确认未使能，不等于已物理停稳；任何未确认或进程未退出，都不打开下一趟。
6. 第一趟选 `0`；每趟结束由操作者另启新会话，可选 `25`、`50`、`75`、`100`。原 PD 不变，沿用 VR 候选的逐轴前馈限幅和爬升。正式 VR/DP 配置不因回放结果自动改变。

每趟系统盘 `~/.cache/openarm-dp-field/fixed-replay/<纳秒>/manifest.json`、`trace.jsonl` 独立记录。
`index` 0–149 起点、150–349 运动、350–499 终点；负索引为进入回放前。每侧按 `feedback` 的采样时间
（`dispatch` 行中 `stamp`）向前匹配最近一次软件派发 `dispatch_ns`，比较其 `command` 与采样 `q`。
`scale` 和 `tau_ff_nm` 是请求前馈，不是电机实测扭矩。中止/未完成的回放不要当作完整结果。

为何不用原 47 号：模型离散姿态检查发现左 link5 与地面重叠（轨迹约 0.9 mm，原过渡约 7.2 mm）。不据此判定实际碰撞，保留原离线试验不改。
新候选为 **23 号，第 32–52 帧**，10 Hz 指令半速线性插值。左/右 J4 变化约 12.23°/1.49°，右肘激励小，不用这一个片段确定全工作空间的最终参数。
该片段运动段 MuJoCo 全臂 RMS（仿真扫描的原 PD、0/50/100% 无额外分轴限幅）为 2.104°/1.087°/0.275°。这些不是现场测量。
